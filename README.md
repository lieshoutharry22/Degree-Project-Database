# Aeronautical Engineering Lab Reports

This repository contains the LaTeX source code, MATLAB-generated figures, and technical documentation for aeronautical engineering laboratory assessments. The reports cover data analysis and structural mechanics across multiple experiments, including control systems (PI controllers) and non-linear equilibrium testing.

The source files and directory structure can be uploaded directly to cloud-based editors such as Overleaf.

## Repository Structure

The project is organized into the main LaTeX documents and modular folders for experiment-specific figures and PDFs for final report viewing.
